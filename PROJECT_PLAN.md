## Project Roadmap

Phase 1: Foundations
- Git, repo structure
- GCP setup
- Infrastructure as Code

Phase 2: Data Ingestion
- Batch ingestion from French energy APIs
- Streaming ingestion for mobility events

Phase 3: Processing & Storage
- Spark batch and streaming pipelines
- Lakehouse architecture

Phase 4: Analytics
- dbt models, tests, metrics
- Forecasting

Phase 5: AI Layer
- Embeddings
- RAG-based insights
- Optional agent-based analysis

Phase 6: Production Readiness
- CI/CD
- Observability
- Security and governance
